# Submitted thesis assets

The figures are copied from the active LaTeX source graph corresponding to the
supplied 87-page thesis. The table fragments preserve the audited original
reference values, including rows originally embedded directly in the manuscript.
They are retained to make corrections traceable.

The source PDF is identified in `../manifest.json` by SHA-256. The manuscript
PDF and full LaTeX source are not part of this asset release.

Some original values were affected by the scoring issues documented in the
audit. Use [the corrected results](../recomputed/README.md) for the repaired
implementation, and [the gallery](../README.md) to compare the figure versions.
