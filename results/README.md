# Final V11 thesis figures and results

The final V11 release, `results-v11-2026-09-15`, includes all 35 analytical
figure files, one cover emblem, ten table fragments and 268 aggregate input CSVs.
See the [V11 numerical reference](../docs/V11_RESULTS.md),
[version record](../docs/submission/v11_20260915/README.md),
[reproduction instructions](../docs/REPRODUCING_RESULTS.md) and [file manifest](manifest.json).

- `recomputed/`: final V11 figures, table rows and aggregate inputs.
- `submitted/`: historical 2026-09-14 assets, retained to document corrections.
- `static/sigillum.png`: the cover emblem, outside the statistical pipeline.

V11's maximum changed-transition accuracy is **16.3%**. Its **grouped** false
persistence range is **76.3%–100.0%**, over parsed changing transitions.
Earlier figures and table rows must not be quoted as V11 results.

Previews show V11. Filenames retain their original exporter names: the framework
is manuscript Figure 1, `Figure_1_information_ladder_print` is manuscript Figure 2,
and `Figure_4_persistence_heatmap_left_right_grouped_print` is manuscript Figure 4.
Each entry offers the final V11 asset and an explicitly labeled historical copy.
