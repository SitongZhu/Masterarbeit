# Synthetic interface examples

These records are invented and contain no survey respondent information.
They illustrate only the JSON/JSONL fields, not the complete thesis prompt.
The actual prompt templates are in `code/01_prompt_generation/scripts/`.
The intentionally mismatched example prediction demonstrates that `label`
is the reference response and `predict` is the model answer.

For a main-pipeline local experiment, place compatible JSONL files under the
appropriate task directory, alongside matching wave-list RDS artifacts.
Do not mix these synthetic examples with thesis generations.
